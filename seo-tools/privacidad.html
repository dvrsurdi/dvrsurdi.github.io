Política de privacidad — G_Analyzer

Esta aplicación accede, mediante OAuth 2.0, a datos de Google Search Console (webmasters.readonly) y Google Business Profile (business.manage) de las propiedades que el propio desarrollador administra.

Los datos se descargan a una base de datos local (SQLite) y a archivos en el propio equipo del desarrollador, con el único fin de generar informes de SEO para uso personal. No se comparten con terceros, no se venden, no se usan con fines publicitarios y no se suben a ningún servidor ajeno.

La aplicación es de un solo usuario (el propio desarrollador) y no se ofrece públicamente. El consentimiento puede revocarse en cualquier momento desde myaccount.google.com/permissions.
